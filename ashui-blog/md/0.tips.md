# 显示外部资源需要开启网络权限

```json
{
  "expo": {
    "android": {
      "usesCleartextTraffic": true, //允许http
      "permissions": ["INTERNET"]
    },
    "ios": {
      "NSAllowsArbitraryLoads": true, //允许http
      "permissions": [
        "NSCameraUsageDescription",
        "NSPhotoLibraryUsageDescription"
      ]
    }
  }
}
```

图片使用 expo-image

图片名尽量使用纯数字

静态资源文件 需要设置请求正确的请求头
